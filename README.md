# printqueue
Print Queue Management System

PrintQueue is a web-based application designed to simplify and organise document printing requests. Users can upload their documents along with their name, page count, and required number of copies.

The submitted requests are received by the printing service provider and managed through a queue based on the FIFO (First In, First Out) principle, ensuring that print jobs are processed in the order they are received.

Core Concept
FIFO (First In, First Out) – Queue Data Structure

Objective
To provide an organised and efficient way to manage print requests, reduce waiting time, and simplify the printing process.
